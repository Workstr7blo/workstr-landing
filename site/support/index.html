What zaps fund

A local-first trainer, then encrypted backup, then growth without lock-in.

The published target is 50,000 sats per month. It is denominated in sats because donations arrive in sats, so the receipt meter can compare income to cost without a fiat price feed.

v1.0

Public release polish

Finish the first public tag: offline training, starter programs, signed catalog imports, optional identity, workout sharing, JSON export/import, and release QA on real devices.

v1.1

Live-training modes

Add EMOM mode, split the runner along the seams that exposes, then build supersets and backfill tests for the pure training modules.

Encrypted Nostr backup

Open a capped self-serve alpha: signed access, NIP-42 relay auth, NIP-44 encrypted kind:30078 private records, sync queue, restore, quotas, and off-machine relay backups.

v3

Supporter-powered growth

Milestone zap prompts, supporter recognition from public receipts, user-published programs, media hosting when it is justified, push notifications, and coaching tools.
